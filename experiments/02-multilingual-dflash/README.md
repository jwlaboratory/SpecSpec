# multilingual — does LoRA specialization work? (5 languages, 6 adapters)

Train the z-lab DFlash drafter on **polish · korean · italian · japanese · german**
(synthetic prompt sets, 800 train / 100 val / 100 test each, answers regenerated by
the target — self-distillation) two ways:

- **own** — one rank-16 LoRA per language (800 examples each)
- **combined** — a single rank-16 LoRA on all five languages together (4000)

then benchmark a **5×3 matrix** on each language's held-out test split:
base (no adapter) vs own-language LoRA vs combined LoRA. No full fine-tunes —
`../README.md` already showed full FT ≈ base on two domains.

## Takeaways

1. **Specialization works — everywhere.** Every language improves under its own
   LoRA; with base rates this low the *relative* gains are large (korean +46%,
   polish +42% relative acceptance).
2. **One combined adapter ≈ five specialists.** Within ±0.1pp of own-language
   LoRAs on every language — five languages do not interfere inside a single
   rank-16 adapter. Operationally that's the more useful artifact: one adapter to
   serve instead of five (though `../../router/` makes per-request selection free
   anyway).
3. **Gains are inversely proportional to base quality.** Biggest lifts where the
   drafter is worst (korean/polish, base ~3%), smallest where it's best
   (italian/german, base ~7–8%). Specialization buys the most exactly where the
   pretrained drafter fails.
4. **Absolute acceptance stays low (4–8%)** vs English-ish domains (11–28% in
   `../results/`): the 1B drafter is fundamentally weak on non-English text, and
   800 prompts of rank-16 LoRA narrows — but nowhere near closes — that gap.
   Next levers: more data per language (the vLLM prep makes 8000/language cheap)
   and/or higher rank.

## Rank scaling — deeper LoRA helps (r64 vs r16)

Re-ran the own/combined adapters at **rank 64 (α=128)** on the same data:
r64 > r16 on **5/5 languages**, biggest extra gains where base is weakest
(korean 3.5% → 5.1% (r16) → **5.8%** (r64) = +66% relative; polish +61%).
Combined r64 ≈ own r64 (still no interference). Rank was partially binding —
more capacity (or data) likely helps further on the weak languages.
→ rank-variant results and charts now live in `../07-rank-ladder/`
